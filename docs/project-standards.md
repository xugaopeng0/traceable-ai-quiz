## 1. 产品与交互

### 用户、场景和页面

教师是组卷、审核、发布、导出的使用者；本班学生无权访问教师模块。评测由班级教师操作，小组成员以实际教师账号运行，不新增绕过班级权限的“评测管理员”。

| 路由 | 主要场景 | 空状态与下一步 |
| --- | --- | --- |
| /classes/:classId/quiz/runs | 选择讲义、创建及查看任务 | 尚无组卷任务，提供“新建组卷” |
| /classes/:classId/quiz/runs/:runId | 查看执行进度、失败原因、进入题卷 | 未生成可审核题目，展示任务原因；不伪造题卡 |
| /classes/:classId/quiz/papers/:paperId | 核对来源、编辑、审核、发布和导出 | 0 题时禁止发布，提供返回任务入口 |
| /classes/:classId/quiz/evaluations | 选择评测集、对比运行、标注与报告 | 无基线显示“尚未建立基线”，不能显示门禁通过 |

详情资源不存在用 404 页面，不等同于列表为空。列表四状态：loading（首次请求未完成）、ready（请求成功且有数据）、error（请求失败）、empty（请求成功且 items=[]）。刷新已有列表时保留旧内容并标明正在刷新；失败展示请求号和重试入口，禁止把网络故障变成空列表。2 秒轮询仅在任务活动时运行；失败后按 2/4/8/16/30 秒退避，恢复成功后回到 2 秒。

统一术语：任务“成功”指足额通过自检；题目“审核通过”指教师批准当前修订；“已发布”指形成不可变题卷快照；“来源失效”指权限/来源代次不满足当前使用条件；“门禁阻断”指证据不足，不能当作质量失败或通过。“学生版导出”是教师下载不含答案的文件，不是开放学生作答入口。

表单在首次失焦校验该字段，字段已报错后随输入重校验；提交时整表校验，服务器始终再次校验。整数禁止小数、NaN 与越界；未知题型/状态不转为默认值。提交中禁用重复点击，网络结果未知时用原幂等键查询/重放，不能自动生成新任务。

视觉基线：间距使用 4/8/12/16/24/32/48 px；字号使用 12（辅助）、14（正文）、16（卡片标题）、20（页标题）、28（主标题）px，正文行高 1.5。主表面 #FFFFFF、页面底色 #F6F7F9、主文字 #242A32、强调色 #A72C35；错误、成功和失效同时使用文字/图标，不能仅靠颜色。按钮最小高度 36 px、表单控件 40 px；检查 375/768/1440 px 视口，无水平溢出或遮挡。

### 状态与允许操作

| 对象与状态 | 允许 | 禁止 |
| --- | --- | --- |
| run queued/running | 查看、取消 | 发布关联题卷、修改任务参数 |
| run succeeded/partial/failed/cancelled | 查看、以新任务重新组卷 | 继续向旧任务追加结果 |
| item draft + check pending/fail/inconclusive | 编辑、退回、重生成 | 审核通过 |
| item draft + check pass + source valid | 编辑、审核、退回、重生成 | 未审核直接发布 |
| item approved | 查看；草稿卷中可编辑但必须撤销原审核并复检 | 修改后沿用旧审核 |
| item rejected | 编辑、重生成 | 不经复检重新批准 |
| source invalid | 查看失效原因 | 读取失效原文、审核、发布、导出 |
| paper draft | 逐题处理；关联任务终结后按条件发布 | 导出为已发布题卷 |
| paper published | 查看；来源有效时导出；整卷重生成新卷 | 直接修改已发布快照 |
| eval queued/running/awaiting_annotation | 查进度，待标注时提交本人标签/裁定 | 缺指标或标签时冻结基线 |
| eval completed | 查看报告，条件满足时冻结基线 | 原地改样本或运行配置 |
| eval failed/cancelled | 查看失败记录，以新实验重跑 | 恢复写入旧实验、冻结不完整结果为基线 |

评测暂无网页取消入口；不新增未规划接口。状态变化由服务端条件写入，客户端按钮只是提示。

### 导入导出

首期不新增网页导题/导卷。评测集通过受控 JSONL 导入：UTF-8、最多 5 MiB、500 行，每行 1 个 case；先校验整批字段、重复 ID、班级及来源，全部通过后事务写入，任一错误则整批 0 行写入。错误包含 1 起始 line、field、code、message；非法 UTF-8 或整文件超限报告文件级错误。错误详情最多 100 条，同时给出总错误数和 truncated 标记。

导出限定 JSON/Markdown、student/teacher 两种 variant，每次 1 份已发布且当前有效的题卷，最多 30 题、UTF-8 结果最多 5 MiB；超限返回 422 EXPORT_LIMIT，不返回截断的“成功”文件。试题版不含标准答案/解析；教师版可包含。权限和来源校验在导出时再次执行。评测报告 JSON 的 500 case × 最多 3 次运行同样限制 5 MiB，超过则明确报错，不新增批量异步导出能力。

## 2. 后端与接口

依赖方向：HTTP handler → 应用/领域服务 → 仓储及网关接口；SQL/Qdrant/HTTP 客户端实现这些接口，不能让领域层依赖 net/http 或前端类型。handler 负责解码、大小、字段类型和认证上下文；服务层负责权限、状态、来源与配额；数据库负责外键、唯一键及并发不变量。前端校验不能替代后两层。

接口沿用 /api/classes/{class_id}/quiz，不为单一模块强加 /v1 破坏旧路径。兼容性新增字段通过契约审查；删除字段、改变类型/语义或新增必填字段先提独立兼容变更。请求/响应 snake_case，表、列 snake_case，Go 类型遵循项目惯例，ID 不暴露顺序自增值。

筛选、排序与分页参数严格白名单：status 不属于对象枚举、未知 sort、空/非法 cursor、limit=0 或 101，均为 422 VALIDATION_ERROR；未知查询参数也报 422，绝不忽略筛选后返回全量。默认 created_at DESC,id DESC；任何非唯一排序字段后追加 id 作为兜底，游标包含全部排序键。

每个写接口在契约声明“业务幂等 / Idempotency-Key / revision 条件写”之一，不因重试重复创建记录。事务只包含数据库一致性操作，禁止夹带网关、Qdrant、文件存储、网络通知等外部调用；跨系统工作先持久化意图，再由有幂等保护的 worker 执行。所有外部调用都有超时和取消传播。

地址、密钥、模型、重试、并发与大小上限通过服务端环境或配置注入，启动校验类型、范围和必填项；配置可调不等于用户可任意选择外部地址。记录有效配置版本/哈希但不输出密钥。未知配置值不静默回退成宽松行为。

## 3. 安全

默认拒绝：每个操作校验主体身份、班级关系、角色、资源归属及当前状态。路径 class_id 与目标资源不一致、来源不属于题目、题目不属于题卷均失败；不能只验证一个 ID 后相信其余 ID。越班资源返回 404，本班无教师角色返回 403。

附件读取必须经过讲义或题目来源业务服务鉴权。已有按 handout_id 的下载路由只有在服务端反查班级及业务权限后才可复用；禁止新增通用 /files/{id}、按存储名或磁盘路径下载的接口。失效来源不得通过题目快照绕过附件权限。

浏览器会话只放 HttpOnly、SameSite Cookie，HTTPS 环境启用 Secure；不把会话或 Bearer 存入 localStorage/sessionStorage。脚本令牌仅通过受控环境或进程内存传递，不写 URL、日志和仓库。退出/撤权按已有会话机制生效。

课程网关密钥在每次交接、疑似泄露时立即轮换，其他情况下每 90 天复核并轮换；更新服务端密钥、验证新密钥、撤销旧密钥并记审计，不能用恢复旧备份重新启用已撤销凭证。账号口令/密钥不进入测试夹具。

出站只允许服务端配置的课程网关、MySQL、Qdrant 和当前基础平台确实需要的服务。网关 origin 与端口精确白名单，默认 HTTPS；本机 HTTP 仅限明确的开发配置。禁跨 origin 重定向；用户、讲义、模型输出中的 URL 不能触发下载、HTTP 工具或改变目标。地址校验覆盖解析结果，拒绝云元数据/环回等意外目标；内部数据库/Qdrant 仅由独立固定配置访问，不混用网关白名单。

输入采用长度、枚举、结构与业务校验；输出按上下文转义，Markdown 禁原始 HTML、脚本链接和未经许可外链资源。错误不返回内部路径、SQL、密钥或完整模型输出。

依赖漏洞扫描在每个 PR（覆盖两套依赖）和每周一次执行，工具版本随 CI 固定；目标使用前端依赖审计和 Go 漏洞扫描，严重/高危依赖发现必须修复或具备书面风险例外，扫描服务不可达为 blocked，不能伪称零漏洞。自动化尚未落地前用同等手动记录，不声称已持续监控。

## 4. 测试与缺陷口径

用例来自 OpenSpec Scenario、OpenAPI、状态矩阵和已修复缺陷。每层按 normal（正常路径）/failure（失败路径）/boundary（边界）分类；边界至少覆盖数量 0/1/30/31、分页 0/1/100/101、引用 start=end/越界、Unicode emoji、版本冲突。

单元测试覆盖配额、规则、指标；契约测试覆盖路由/鉴权/错误/JSON Schema；真实 MySQL/Qdrant 集成覆盖外键、租约、恢复、跨班和并发；浏览器测试覆盖四状态与审核发布。真实模型评测独立于可离线的规则测试，不能用 mock 证明模型正确率。

每次测试生成独立 run_id、数据库/schema 或资源前缀和 Qdrant 集合，讲义文件只写测试临时目录。清理只针对本轮标识，禁止指向演示/实际数据卷；测试账号、端口和数据源显式配置。故障注入只作用于隔离环境。

目标完整门禁：规约 → Go test/vet → 前端类型与构建 → 契约 → 隔离集成 → 浏览器 → 16 例 AI 快速集 → 依赖扫描，任一步非零即整体失败；缺依赖/密钥或未执行必需检查为 blocked，不返回“通过”。完整真实质量报告是影响质量变更的附加合并条件；基线未建立时只能推进明确标识的基线建设任务，不能标记质量门禁通过。

阶段说明：v0.0.1-skeleton 的 npm run check 只实现骨架子集（规约、契约、容器 Go/前端构建、隔离启动与日志验收）；上段的完整业务门禁尚未实现。浏览器壳回归单独以 test:browser 运行，不能将骨架通过解释为数据库、AI 或扫描通过。

测试开始前为每例固定判定信号：HTTP 状态+code、持久化任务/自检/审核状态、数据库行数和 revision、外部调用次数、附件可读性及 UI 状态。日志和请求号用于关联，HTTP 200 或绿色提示不能独立决定成功。

| 缺陷类别 | 判定方式 |
| --- | --- |
| 被当成成功 | 预期失败却返回成功状态、空错误或伪造结果，例如依赖断开后显示正常空列表 |
| 被放行 | 未授权读取、无效题目通过审核/发布、产生禁止的写入或外部调用；即使 HTTP 返回错误也算缺陷 |
| 被误拒 | 满足权限、状态及参数条件的正常/边界请求被拒绝；用相同前置状态复现 |
| 未处理故障 | 超过规定超时、无限重试、孤立 running 任务、无错误码或无恢复路径 |

同一问题可标多类；数据泄露、越权或无效发布不因最终失败码而降低为“无影响”。复现记录包含固定版本、前置条件、操作、预期信号、实际信号及请求号。

## 5. 部署与运维

分 dev/test/demo 三套独立配置和数据卷，测试不能复用 demo 数据；CI 不注入真实学生资料。依赖锁文件、基础镜像版本/摘要、构建提交号和配置模板共同固定环境，禁止发布使用未记录的 latest 镜像。实际服务启动命令在基础导入后补齐，不在文档虚构可运行入口。

目标探针：GET /api/healthz 为进程存活，GET /api/readyz 检查 MySQL/Qdrant 与迁移版本；探针单次预算 2 秒，依赖失败 readyz=503，healthz 仅进程异常时失败。网关不在探针中发收费推理请求；缺配置单独报告生成不可用。Compose 每 10 秒检查、超时 2 秒、连续 3 次失败不就绪。

骨架阶段提供免认证 /health 与本站 /api/health 别名，只检查进程；不接 MySQL/Qdrant、不提供 readyz，不声称业务就绪。nginx 原生错误由适配器转为 JSON，并移除请求查询上下文；默认绑定 127.0.0.1:18080，避免与课程平台 8080 冲突。

收到 SIGTERM 后 api/worker 停止接新任务及新写请求，api 最多等待 15 秒完成在途请求；worker 在 20 秒内取消外部请求并停止续租，未提交结果交给租约恢复，不能把中断误记为成功。Compose 停机宽限 30 秒。启动顺序为依赖就绪 → 单独执行迁移 → 启动 api/worker → web；不能让多个服务同时抢跑迁移。

JSON 日志固定字段：timestamp、level、service、env、commit、request_id、class_id（适用时）、resource_id、job_id、event、duration_ms、error_code。日志不含 Cookie/Authorization、口令、完整讲义或模型原文。记录租约丢失、拒绝访问、配置版本切换和发布行为，按请求号关联。

发布采用新增兼容列/表 → 兼容应用 → 验证 → 再做独立清理变更；迁移先备份。回退应用至兼容版本、关闭新功能并停领任务，保留新表；不可逆数据操作单独审批与恢复演练，不强制提供破坏性 down SQL。

本机课程演示的备份目标为 RPO≤24 小时、RTO≤2 小时：每天备份 MySQL 与私有讲义，保留 7 天，备份清单记录时间、提交号、迁移与内容哈希；Qdrant 可从权威正文重建，保留配置/索引版本。首次发布前和每次破坏性数据变更前演练恢复。目标不等于已达成，实际恢复耗时与索引重建时间必须记录，超目标即失败。备份不放 Git，不与在线数据共用唯一存储副本。

## 6. AI 与数据

工具和模型只调用已有服务层，不绕过权限直连 SQL、Qdrant 或文件；本期出题不增加自主工具执行。提示词正文、类型、版本、SHA-256、创建者和时间作为不可变版本记录入库，源码模板同时受版本控制；每次生成与判定引用精确版本，修改不能覆盖历史。输出必须经过结构/来源/语义校验，不编造依据，缺依据要失败或拒答。

建立 16 条版本化快速回归：8 条可回答/可生成正常例、4 条必须拒答或拒绝生成例（无依据、超范围、越班、无可用来源）、4 条对抗/边界例（伪造引用、提示注入、Unicode、无效结构）。确定性安全断言要求 16/16；真实模型语义指标另走冻结基线，快速集不能替代 40-50 条问答集与 100-150 题人工标注集。无密钥 CI 用明确标记的固定输出回放验证规则，不声称已检验真实模型质量。

新增表/列 snake_case，ID、class_id、创建时间及操作者按实体适用性记录；可修改实体有 updated_at、updated_by、revision，不可变尝试/审核/基线只追加历史。删除也要审计，不以 soft delete 代替权限过滤。

| 数据级别 | 例子 | 保存与访问 |
| --- | --- | --- |
| 公开 | 已授权种子、合成评测样本、规约 | 可进 Git；发布前审查 |
| 内部 | 配置哈希、脱敏运行统计、资源 ID | 仅授权教师/维护者；不含正文 |
| 私有 | 讲义、切片、题目、回答、标注原文 | 班级权限；备份同等级保护 |
| 凭证 | 网关密钥、会话、密码哈希 | 不出日志/前端/Git；最小权限与轮换 |

原始模型响应最多 7 天、普通日志 14 天、备份 7 天、非正文审计 180 天；题目及标注等业务数据保存至班级删除或课程验收后 30 天（以先发生者为清理触发点），真实留存策略需在部署配置与使用说明中告知。清理失败可重试并留审计；不得静默丢失必要审核记录。

删除清单必须覆盖：MySQL 业务正文及派生快照、Qdrant 点、私有讲义卷（首期无独立对象存储）、原始响应/报告、缓存（首期不引入新缓存）和备份。在线删除后立即撤销可读性，24 小时内清理在线副本；备份至多保留剩余 7 天，恢复时重放删除清单再开放服务。仅保留不含正文/个人资料的必要失效审计；保留源 ID/哈希不得恢复读取已删除正文。

## 7. 评审与完成定义

**完成定义：对应规约及契约已更新，正常/失败/边界用例和必跑门禁通过，权限与来源检查无绕过，必要质量与部署证据齐全，文档及回退方案一致，并经另一成员评审后才可标记完成。**

每个 PR 一个主题，人工修改默认不超过 400 行且不超过 20 个文件；依赖锁、自动生成契约等不计行数但单独注明。首次基础导入或必要跨模块变更可超限，须列清文件、原因与分块评审顺序。不得为满足上限拆出无法验证的半完成行为。

评审检查表：范围/Scenario、接口兼容、非法筛选、逐资源授权、来源代次与修订、事务无外部调用、幂等与排序、日志和数据留存、正常/失败/边界结果、评测及回退证据。PR 写明执行命令、结果与未执行项；必跑门禁缺失不能记为完成。

例外必须在 PR 或版本化记录中注明规则、理由、风险、补偿措施、负责人、另一成员审批与到期日（默认最多 7 天）；到期未处理视为阻断。例外不能把未执行或失败的检查写成通过，也不能豁免跨班泄露、伪造来源或未审核发布。
