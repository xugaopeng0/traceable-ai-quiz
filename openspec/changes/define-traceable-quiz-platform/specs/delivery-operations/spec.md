# Spec Delta

## Purpose

定义模块在本机部署、依赖故障、验证和交付时必须满足的运行约束，使开发与演示环境可复现，并明确真实执行证据与规划目标的区别，避免提交敏感资料或报告未执行的验收结果。

## ADDED Requirements

### Requirement: 私有数据与服务端网关
系统 SHALL 仅由服务端调用课程网关，浏览器只访问本站 /api；数据库、向量库和私有讲义不暴露为公共服务。模型输入中的讲义内容作为数据而非指令，不能改变权限、范围或校验策略。

#### Scenario: 恶意讲义内容

**前置条件**：本班已发布讲义含有要求读取其他班级或泄露密钥的文字，生成任务只能访问其候选白名单。

**操作**：讲义包含要求读取其他班级或泄露密钥的文字

**可观测结果**：生成只使用当前授权候选，校验规则不变，响应与日志不含密钥

### Requirement: 可复现部署
交付 SHALL 提供 Compose 的 web、api、worker、db、qdrant 服务及环境变量模板；应用容器以非 root 和只读根运行，持久化写入显式卷，worker 对讲义卷只读。缺少网关配置时明确不可生成，不能静默使用假模型。

#### Scenario: Qdrant 或网关不可用

**前置条件**：存在 1 个 running 任务，单次网关调用超时为 60 秒，每题位总尝试预算为 3 次。

**操作**：断开任务所需的 Qdrant 或网关连接

**可观测结果**：记录 DEPENDENCY_UNAVAILABLE 或 GATEWAY_TIMEOUT；单次网关请求最多等待 60 秒，单题位总尝试不超过 3 次；预算耗尽后题位失败，任务依据有效题数进入 failed 或 partial，不将跳过检查的候选标为 pass。

### Requirement: 检查与证据
交付 SHALL 通过 OpenSpec 严格校验、Go test/vet、前端构建、接口契约、MySQL 集成测试和必要浏览器回归；部署与性能结论必须有实际命令、版本、时间及结果。已有 SSE 问答保持真实流式与 nginx 不缓冲。

#### Scenario: 未执行容器验收

**前置条件**：当前仅有规划文件与 OpenSpec 校验输出，尚无业务代码和 Docker 运行证据。

**操作**：仅完成文档和规约验证

**可观测结果**：验证记录明确业务、Docker 和模型质量验收未执行，不将它们标记为通过

### Requirement: 存活就绪与优雅停机
系统 SHALL 区分 /api/healthz 存活与 /api/readyz 就绪，探针预算 2 秒；MySQL/Qdrant 或迁移未就绪返回 readyz=503，不发送付费网关推理探测。停机停止接新任务，API 在 15 秒内结束等待，worker 在 20 秒内取消调用并停止续租，容器宽限 30 秒。

#### Scenario: 依赖不可达但进程存活

**前置条件**：API 进程正常运行，MySQL 在隔离环境被断开。

**操作**：分别请求存活与就绪探针。

**可观测结果**：healthz=200，readyz 在 2 秒内返回 503；不返回凭证，付费模型调用数为 0。

#### Scenario: worker 在生成中停机

**前置条件**：worker 正持有任务租约并执行网关调用，当前没有可提交结果。

**操作**：向 worker 发送 SIGTERM。

**可观测结果**：立即停止领取新任务，在 20 秒内取消调用并停止续租，不把中断标记 succeeded；租约到期后其他 worker 可按既定预算接管。

### Requirement: 出站白名单与扫描
网关出站 SHALL 限定服务端 origin/端口白名单，禁止跨 origin 重定向及用户/模型指定地址；凭证按交接、泄露事件和 90 天复核策略轮换。依赖扫描每 PR 和每周执行，未执行或服务不可达标记 blocked，不伪报通过。

#### Scenario: 模型提供其他出站地址

**前置条件**：服务端仅允许课程网关 origin G1，模型输出要求请求不在白名单的 G2。

**操作**：处理该模型输出。

**可观测结果**：G2 出站请求数为 0，不转发 Authorization，不把该输出当作可执行工具指令。

### Requirement: 数据删除与恢复目标
部署 SHALL 提供每日备份、7 天保留与恢复演练，以 RPO≤24 小时、RTO≤2 小时为待实测目标；删除清单覆盖业务正文、快照、向量、文件、报告、缓存及备份。在线立即撤销读取，24 小时内清理在线副本，恢复备份后先重放删除清单再开放服务。

#### Scenario: 恢复备份不复活已删除讲义

**前置条件**：备份包含讲义 H1，备份后 H1 已删除，持久化删除清单保留该事件。

**操作**：在隔离环境恢复备份并按恢复步骤开放服务。

**可观测结果**：开放前重放删除清单；H1 的正文、快照和向量不能被读取或检索，关联题目来源失效；记录实际恢复耗时，超过 2 小时不得标记目标通过。

### Requirement: 分层测试与完成门禁
测试 SHALL 按正常/失败/边界组织，固定 HTTP、业务状态、数据变化和外部调用信号，并隔离测试数据。一键门禁 npm run check 中任一步失败或缺失必需依赖须整体非零退出；完成定义及评审遵循 docs/project-standards.md，不能用绿色 UI 或 HTTP 成功码替代安全副作用检查。

#### Scenario: 响应拒绝但实际泄露仍是缺陷

**前置条件**：越班附件请求的预期为 404 且文件读取次数为 0。

**操作**：故障实现先读取并发送附件字节，随后记录 404 错误，运行对应安全用例。

**可观测结果**：以实际文件读取/发送信号判为“被放行”，测试与整体门禁失败；不能根据日志中的 404 标记通过。
