# Spec Delta

## Purpose

规定每道题如何绑定可核对的讲义证据，统一位置和字符的含义，并在讲义重建、删除及并发发布过程中检查有效性，防止题目继续引用与原文不符或用户已无权访问的材料。

## ADDED Requirements

### Requirement: 服务端生成可信来源
每条来源 SHALL 包含 handout_id、generation_id、chunk_id、ordinal、locator、char_start、char_end、quote 与内容哈希。模型只选择服务端候选 chunk_id 及切片内区间；讲义身份、代次和定位由服务端补全并验证，禁止信任模型生成的 URL 或路径。

#### Scenario: 模型伪造切片

**前置条件**：任务白名单只含切片 K1 和 K2，另有不在该班范围内的切片 K3。

**操作**：模型引用不在该任务候选列表的 chunk_id

**可观测结果**：返回 SOURCE_OUT_OF_SCOPE 自检失败，不查询或暴露其他班级正文

### Requirement: 统一字符与定位语义
字符区间 SHALL 以当前代次规范化全文的 Unicode 码点为单位，0 起始、左闭右开；切片内 quote_start、quote_end 同样以码点计数并换算为全局区间。ordinal 为 0 起始；PDF 页、PPT 页、Word 段和 TXT 行号为 1 起始、两端包含。quote 必须与区间原文逐字相等。

#### Scenario: 中文及非 BMP 字符

**前置条件**：切片文本为“甲😀乙”，码点区间为 [0,3)，其中 emoji 的码点区间为 [1,2)。

**操作**：前端请求并显示引用 [1,2) 的证据

**可观测结果**：quote 为“😀”，只高亮 1 个 emoji，不包含“甲”或“乙”；后端与前端区间一致。

### Requirement: 授权定位与失效
系统 SHALL 在读取、审核、发布、导出时回查当前班级权限和 active_generation_id；来源过期或删除后标记 invalid，禁止审批、发布和导出。有效来源提供经本站鉴权的原文入口与文本高亮；格式不能原生跳转时展示可靠定位标签与片段，不伪造精确跳转。

#### Scenario: 删除或重建讲义

**前置条件**：题目绑定讲义 H1 的代次 G1，题目及其所属草稿卷已持久化。

**操作**：题目绑定代次已不是该讲义活动代次，或讲义已删除

**可观测结果**：列表显示来源失效，相关题卷不可发布或导出，来源入口不暴露历史正文

### Requirement: 发布竞态一致性
发布 SHALL 与讲义活动代次切换和删除保持串行一致性；不得以过期的缓存校验结果完成发布。已发布题卷在来源随后失效时仍必须实时禁止导出或供后续模块使用。

#### Scenario: 发布与重建同时发生

**前置条件**：题卷全部题目已审核，均引用活动代次 G1；另有 G2 等待切换。

**操作**：教师发布事务与活动代次切换竞争

**可观测结果**：按同一锁协议先后执行，后执行的访问检查能发现失效，不出现绕过检查的可用题卷
